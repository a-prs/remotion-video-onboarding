## 2026-08-28.4

Правки по итогам живого прогона двух реальных роликов (45с и 9:43) — спасибо за детальный отчёт
с измерениями. Каждый пункт был реальным дефектом на реальном материале, не гипотезой.

- **Границы дублей/фальстартов** больше не берутся напрямую из `word.start`/`word.end` (DTW-лаг
  0.2-0.8с оставлял хвост вырезанного слова в кадре — «чтобы… чтобы»). Новая цепочка
  `scripts/vad.py` (карта речевой активности) → `scripts/refine_cuts.mjs` (ставит границу по
  реальной паузе или, если фразы слитные, по локальному минимуму энергии) даёт точные границы.
  Шаг 6 п.2 теперь выдаёт `pairs.json` (пары индексов слов), а не тайм-коды напрямую.
- **Монтаж без переэнкода** — новый `scripts/plan_cut.mjs` считает план (какие куски исходника
  оставить) вместо физической резки+конкатенации; Remotion играет план через `<Sequence>` +
  `<OffthreadVideo trimBefore>` прямо из исходника — расхождение звука/картинки было 0.86с на 48
  стыках у cut+concat, стало 0.04с. Legacy-путь через `cut_silence.py` (один физический mp4)
  остаётся доступен для случаев, когда физический файл реально нужен.
- **Фантомные субтитры от вырезанных дублей** — слова внутри вырезанного дубля раньше
  примагничивались к границе реза (как и слова у пауз), а не выбрасывались — 7 слов схлопывались
  в 0.05с и рисовали строку с текстом, которого в звуке уже нет. Новая `drop_words_in_cuts()` в
  `cut_silence.py` (legacy-путь) и встроенная логика `plan_cut.mjs` (Sequence-путь) выбрасывают их.
- **Whisper зацикливается на длинной тишине** (на ролике 9:43 с 81% тишины — ~70 повторов одной
  фразы) — новый `scripts/prep_speech_only.py` перед транскрипцией меряет долю тишины и, если она
  доминирует, транскрибирует только речевые участки (с щедрым запасом контекста, не финальным
  тугим `--pad`) во временном файле, `scripts/remap_words.py` возвращает тайм-коды на оригинал.
- **BPE-токены вместо слов** у локального `toCaptions()` на русском (`тест|ов|ый` вместо
  «тестовый») — SKILL.md теперь требует склейку по ведущему пробелу токена. У Groq-движка
  (`2026-08-28.3`) этой проблемы нет вообще — ещё один аргумент в его пользу.
- **Windows**: `ffprobe` не на PATH (путь к бинарнику из `@remotion/compositor-win32-x64-msvc`),
  `npx remotion add` требует полного имени пакета (`@remotion/google-fonts`, не `google-fonts` —
  иначе тихо ничего не делает), whisper.cpp только версии 1.5.5 (новее — 404), забитый диск даёт
  вводящую в заблуждение ошибку `Failed to fetch` вместо явного «нет места» — все задокументированы
  в `references/os-install.md`.
- Два примитива банка сломаны против текущих версий `@remotion/*`: `FxGlowText.tsx` (`glow()` —
  `intensity`, не `opacity`) и `RoughAnnotate.tsx` (`Bracket` — булевы пропсы `bracketLeft`/
  `bracketRight`, не массив `brackets`) — оба починены.
- Рендер телефонных `.MOV` может падать по памяти компоновщика на Sequence-пути (частая перемотка
  к далёким опорным кадрам) — задокументирован проверенный фикс (прокси с частыми keyframe +
  `--concurrency`/`--offthreadvideo-cache-size-in-bytes`) в `references/rendering-sequence.md`.
- Проверка кириллицы у шрифта (Шаг 4) теперь обязательный шаг с конкретным способом, не просто
  «посмотри на subsets» — плюс проверка доступных начертаний и список бесплатных замен для
  коммерческих шрифтов из бренд-гайдов.
- Автопроверки видны, не молчат: `plan_cut.mjs` сам печатает повтор слова на стыке и потерю слов;
  legacy-путь и Sequence-рендер — sanity-check расхождения A/V потоков через `ffprobe`.
- Честно задокументирован случай, который метод в принципе не может решить идеально — фальстарт,
  произнесённый слитно с предыдущей фразой без паузы: граница по локальному минимуму энергии
  приблизительная по определению (`references/rendering-sequence.md`).

**Статус тестирования (важно):** `vad.py`/`refine_cuts.mjs`/`plan_cut.mjs` — присланы уже готовыми
и живьём прогнанными на двух реальных роликах, здесь дополнительно перепроверены офлайн-тестами
на синтетических данных (в т.ч. найден и задокументирован реальный интеграционный баг —
обязательность `PRESNAPPED=1`). `prep_speech_only.py`/`remap_words.py` реализованы с нуля по
описанию техники и покрыты только офлайн-тестами — первый живой прогон на реальном тихом ролике
станет их настоящей проверкой.

## 2026-08-28.3
- Новый опциональный движок транскрипции — Groq API (`whisper-large-v3` в облаке): быстрее и заметно
  точнее на русском, чем локальный `medium` через whisper.cpp, но нужен свой `$GROQ_API_KEY` и это
  платно (кредиты Groq), аудио уходит в их облако. Строго opt-in — спрашивается один раз на проект
  (`transcription-engine: local|groq` в шапке `assets/stylekit.ts`), дефолт остаётся `local`/офлайн.
- Новый `scripts/transcribe_groq.py` — без сторонних Python-зависимостей (multipart-запрос собран
  на stdlib `urllib.request`); сам режет длинные файлы на куски по реальным паузам (Groq ограничивает
  размер загружаемого файла) и склеивает результат обратно в тот же формат `words.json`, что и
  локальный whisper.cpp — дальше пайплайн (дубли/паузы/субтитры) работает одинаково для обоих
  движков.

## 2026-08-28.2
- Поиск дублей/фальстартов (Шаг 6 п.2) теперь ловит НЕСКОЛЬКО подряд оборванных попыток разной
  длины («чувак я» / «чувак я» / «чувак, я даже не думал…») — раньше такие короткие обрывки могли
  теряться в чтении длинного транскрипта, потому что это не точный повтор (n-gram), а обрубленный
  ПРЕФИКС финальной фразы. Новый скрипт-предфильтр `scripts/find_repeat_candidates.py` строит
  список кандидатов (точные + префиксные совпадения) перед прочтением — модель всё ещё сама решает,
  что реально дубль, скрипт только не даёт коротким обрывкам потеряться.
- Границы вырезаемых дублей/фальстартов теперь автоматически подтягиваются к ближайшей реальной
  паузе (новая `snap_cut_boundaries()` в `cut_silence.py`) — раньше рез шёл ровно по тайм-коду
  слова от ASR/LLM без запаса, что могло рвать склейку на полузвуке/дыхании. Только расширяет рез,
  никогда не сужает — безопасно по построению.
