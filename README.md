# remotion-video-onboarding

Claude/Codex skill: полная установка и онбординг монтажа видео через [Remotion](https://remotion.dev) — с пустой машины до первого готового ролика, целиком в диалоге, без единой команды, которую печатаешь сам.

## Что делает

1. **Проверяет и ставит окружение** под твою ОС — Node, FFmpeg, headless-браузер для рендера, whisper для субтитров. Для всего, что трогает систему целиком (apt на Linux) — спрашивает разрешение отдельно, не ставит молча.
2. **Объясняет официальный набор [remotion-dev/skills](https://github.com/remotion-dev/skills)** (12 скиллов) — какой когда нужен, не нужно самому лезть в документацию Remotion.
3. **Спрашивает про визуальный стиль** — цвета/шрифты, или пришли 1-2 референсные картинки, вытащит палитру сама. Дефолт — не клишированный ИИ-фиолет-градиент.
4. **Обрабатывает первое видео**: транскрипция → вырезание пауз по реальной тишине в аудио (не по забагованным тайм-кодам Whisper) → субтитры → выравнивание голоса (без нейросетевых денойзеров — лицензионно чисто, ничего лишнего не ставит) → **обязательно предлагает** 1-3 визуальные вставки по смыслу расшифровки из банка в 51 анимированный примитив, не только по запросу.
5. **Показывает превью** — в Claude Desktop прямо в приложении (Browser-панель вкладки Code), в терминале/Codex — через обычный браузер по localhost.

## Установка

**Claude Code / Claude Desktop:**
```
npx skills add a-prs/remotion-video-onboarding --skill '*' --agent claude-code -y
```
Дальше просто опиши задачу в чате («настрой окружение для монтажа видео») — скилл подхватится сам и поведёт по всем шагам.

**Codex:** формат `SKILL.md` тот же, но раскладка другая — читай [`references/codex.md`](references/codex.md), там же скрипт `scripts/migrate_to_codex.py`, который ставит скилл под Codex и синкает `AGENTS.md` одной командой.

## Внутри

```
SKILL.md                    — весь сценарий, точка входа
scripts/
  cut_silence.py             — вырезание пауз по реальной тишине в аудио
  clean_audio.py              — диагностика и выравнивание голоса
  migrate_to_codex.py         — установка/синк под Codex
references/
  os-install.md               — команды под mac/windows/linux
  audio-pipeline.md           — почему аудио сделано именно так
  codex.md                    — Codex-специфика и ограничения (нет превью-панели)
  marker-action-library.md    — словарь «слово в речи → визуальный примитив»
  primitive-map.md            — какие props у какого примитива
assets/
  stylekit.ts                 — шаблон стиля, скилл перезаписывает под тебя
  primitives/                 — 51 визуальный примитив + karaoke-субтитры (SubtitleTrack)
```

## Почему так

Собрано теми же людьми/тем же движком, что уже гоняет автомонтаж на реальном канале — не теория, портировано из живого прода (вырезание пауз, выравнивание голоса, банк примитивов). Полный разбор технических решений — в [SKILL.md](SKILL.md) и `references/`.
