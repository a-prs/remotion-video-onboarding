# Codex

Codex (OpenAI) с ~декабря 2025 понимает тот же формат `SKILL.md`, что и Claude — это открытый
кросс-платформенный стандарт, не нужно писать для Codex отдельную параллельную документацию.
Codex ищет скиллы в `.agents/skills` (по scope: рабочая папка → выше по дереву → корень репо,
затем пользовательский `$HOME/.agents/skills`) или по старой конвенции `~/.codex/skills` —
конкретный путь зависит от версии Codex, проверить обеими.

## Установка

Не копировать контент руками — запустить конвертер:

```bash
python3 scripts/migrate_to_codex.py
```

Он читает `SKILL.md` этого скилла (frontmatter `name`/`description`), раскладывает копию в
`~/.codex/skills/remotion-video-onboarding/` и добавляет короткий блок в `AGENTS.md` рабочего
проекта пользователя (с маркерами `<!-- BEGIN/END GENERATED -->` — при повторном запуске
перегенерируется только этот блок, ручные правки выше/ниже не теряются). Это тот же паттерн,
что уже использует `digitalsamba/claude-code-video-toolkit` для той же задачи — не изобретать
велосипед.

## Важное ограничение — честно предупреждай пользователя

**У Codex CLI нет браузерной/превью-панели**, в отличие от вкладки Code в Claude Desktop. Это
чисто терминальный инструмент — он может запустить `npx remotion studio` (dev-сервер), но не
может сам «посмотреть» на рендер. Пользователю Codex нужно вручную открыть выведенный
`localhost:PORT` в своём обычном браузере, чтобы увидеть превью — агент не закроет эту петлю
сам. Не обещать то, чего нет.

## Что не меняется

Все шаги SKILL.md (окружение, официальный набор remotion-dev/skills, стайлкит, обработка видео,
обязательное предложение графики) — идентичны что в Claude Code, что в Codex. Разница только в
том, как скилл туда попадает (Шаг 0/1 SKILL.md) и в отсутствии превью-панели (Шаг 7).
