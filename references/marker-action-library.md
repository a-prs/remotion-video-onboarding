# Словарь «маркер → примитив» — только реально существующие компоненты

Спутник `primitive-map.md`: там — таблица всех типов с props и файлами, здесь — те же типы,
сгруппированные по СМЫСЛУ (какая фраза в речи на что указывает), с пометками, чем похожие
варианты отличаются друг от друга (важно при выборе между двумя похожими триггерами).

**Жёсткое правило: здесь только компоненты, которые РЕАЛЬНО существуют в `assets/primitives/`
этого репозитория.** Ничего аспирационного, ни одного «когда-нибудь портируем». Если для фразы
пользователя нет хорошего совпадения ни здесь, ни в `primitive-map.md` — это нормально, см.
правило «новый примитив — всегда предлагай занести в банк» в `SKILL.md`: рисуй с нуля под
конкретный запрос, не притягивай за уши ближайший неподходящий тип и не выдумывай тип, которого
нет. Перед тем как назвать тип пользователю — свериться с `primitive-map.md`, что файл реально
на месте (эта же таблица ниже уже сверена, но сам список примитивов может расти).

## 1. Появление / ввод сущности
Маркеры: *«есть X», «взял X», «подключил X», «Claude / бот / сервер / API / плагин», «вот
инструмент», «знакомься»*
- Одна сущность: `iconTitle` (заголовок с иконкой/брендом) или `heroCard` (если нужен более
  развёрнутый разбор — заголовок+категория+описание+буллеты).
- Несколько сущностей подряд («Claude, Codex, Gemini»): `chapterCards` (обзор N пунктов) или
  `cardPile` (стопка карточек).
- Про `brand=` (логотип вместо эмодзи-иконки) — см. `LogoMark.tsx`: этот репозиторий не содержит
  готовых лого-файлов, `brand` работает только если такой SVG реально положен в `public/logos/`.

## 2. Отрицание / зачёркивание
Маркеры: *«не поможет», «не работает», «не годится», «забудь про X», «это не то», «больше не»,
«мимо», «бесполезно», «уже не», «фигня», «не вариант», «так себе», «не катит», «в топку»,
«нафиг», «забей», «ерунда»*
- `strikeNegate` — термин перечёркивается штампом-отрицанием.

## 3. Связь / стрелка между блоками
Маркеры: *«поэтому», «отсюда», «это ведёт к», «в итоге», «значит», «решает эту проблему», «и
тогда», «из-за этого», «а значит», «как результат», «за счёт этого», «получается», «таким
образом», «приводит к»*
- `spineFlow` — цепочка узлов проблема→решение, связная линия между карточками.

## 3б. Проход по связной цепочке (алгоритм/пайплайн)
Маркеры: *«алгоритм», «по шагам», «как это устроено», «цепочка», «весь путь», «от и до», «как
это работает изнутри»*
- `lensPath` — путь змейкой по экрану, окошко-лупа едет по узлам в такт речи. Мощно для
  «звук-офф»: одна связная линия читается без слов.
- Соседний, но другой смысл — «пайплайн/конвейер/в фоне крутится/цикл» (процесс, не разовый
  путь от и до) → `pipeline`, не `lensPath`.

## 4. Ветвление / разделение
Маркеры: *«разделить», «развести», «два пути», «разветвляется», «отдельно», «каждый в свой»,
«разбить на», «по разным», «либо…либо», «варианты», «две дороги», «тут развилка»*
- `nodeSplit` — узел расщепляется на 2-3 ветки.

## 5. Объединение / слияние / хаос
Маркеры (слияние): *«свалить в кучу», «смешать», «в одну кучу», «каша», «всё вперемешку», «слил
воедино», «объединить»*
Маркеры (беспорядок/боль): *«боль», «ад», «кошмар», «путается», «теряется», «абсурд», «бардак»,
«по колено в…», «замучился», «задолбало», «геморрой», «выносит мозг», «костыли», «всё горит»*
- `chaos` — карточки/лейблы дрожат и наезжают друг на друга, визуал беспорядка. Одна и та же
  реакция что на «свалили в кучу», что на «замучился, бардак» — оба читаются как хаос.
- Обычно за хаосом следует семья №3 (стрелка к решению) — не оставляй хаос без разрешения, в
  муте это читается как «просто трясётся», а не как законченная мысль.

## 6. Рост / падение / динамика во времени
Маркеры: *«растёт», «выстрелило», «взлетело», «увеличивается», «попёрло», «падает», «рушится»,
«просело», «обвалилось», «динамика», «по графику видно», «в гору», «обвал», «рекорд», «скачок»*
- `lineChart` — динамика во времени, одно значение растёт/падает.
- `barsGrow` — сравнение НЕСКОЛЬКИХ категорий/дней столбиками (не одна динамика во времени —
  тогда `lineChart`).

## 7. Числа / счёт / деньги
Маркеры: *«дважды», «два раза», «30 тем», «48 партий», «50%», «полгода», «X рублей», «в N раз»,
цифры вообще, «всего», «целых», «×3», «втрое», «лям», «косарь», «окупается», «экономит N»*
- `countUp` — крупное число накручивается (count-up).
- `duplicate` — «платил дважды/за то же» — два одинаковых чека/счёта появляются рядом с ×2.
- `donutFill` — доля/процент, заполняется по дуге.

## 8. Сравнение / было-стало / до-после
Маркеры: *«а вот», «зато», «было / стало», «до / после», «раньше / теперь», «лучше / хуже», «с
одной стороны… с другой», «в отличие от», «против», «в разы», «не то что»*
- `beforeAfter` — было/стало, до/после, «X вместо Y».
- `codeCompare` — то же самое, но специально для КОДА (две панели кода side-by-side).
- `twoColumn` — простое словесное сравнение двух колонок без «было/стало»-семантики.

## 9. Перечисление / шаги / порядок
Маркеры: *«во-первых… во-вторых», «сначала… потом», «шаг 1/2/3», «N способов», «первое,
второе», «по пунктам», «дальше», «плюс ещё», «и наконец», «три вещи», «пункт первый»*
- `numberedRows` — раскрывается по одной строке в такт речи.

## 10. Акцент / ревил / секрет
Маркеры: *«оказывается», «вот в чём суть», «секрет в том», «вот почему», «главное», «лайфхак»,
«фишка», «а теперь внимание», «внимание», «щас будет», «самое сочное», «спойлер», «та-дам»*
- `spotlight` — затемнение фона, фокус на ключевой карточке (нужно ≥2 карточки для контраста).
- `kineticWord` — одно сильное ключевое слово всплывает (когда акцент на ОДНОМ слове, а не на
  карточке из нескольких).

## 11. Вердикт / галочка-крест
Маркеры: *«работает», «готово», «получилось», «провал», «не взлетело», «да / нет», «верно /
неверно», «плюс / минус», «бинго», «в яблочко», «то что надо», «не прокатило», «фейл», «зачёт»*
- `verdict` — зелёная галочка-штамп или красный крест налетает на карточку.

## 12. Код / терминал / диалог с ИИ
Маркеры: *«команда», «я пишу — он отвечает», «промпт», «в терминале», «код», «запрос», «я ему
пишу», «бот отвечает»*
- `chatBubbles` — переписка с ИИ, реплики печатаются по очереди user↔ai.
- `codeAppear` — код построчно с подсветкой.
- `terminal` — терминал-лог/консоль/CLI (статичный, не живой набор — для живого набора и целого
  окружения смотри `workspaceScene`: демо проекта, IDE, файлы+терминал).

## 13. Цитата / чужая речь
Маркеры: *«он сказал», «мне пишут», «типичный вопрос», «говорят, что»*
- `quoteCard` — цитата с кавычками, автор снизу.

## 14. CTA / финал
Маркеры: *«напиши слово X», «забери базу», «ссылка», «подпишись», «кодовое слово», «пиши под
видео», «до встречи», «залетай», «го», «жду в комментах», «сохрани», «если было полезно»*
- `cardPile` — стопка карточек как CTA-финал.
- `iconPopup` — короткий поп с иконкой, если CTA компактнее и не нужна стопка.

## Ещё реальные примитивы без сильного «семейного» маркера (используй по прямому смыслу)
- `pipeline` — пайплайн, конвейер, «в фоне крутится», цикл, автоматом.
- `funnel` — «из N отбираю K», фильтрую, топ из.
- `timeSpeed` — «за 5 мин вместо 3ч», мгновенно, пока спишь — контраст времени/скорости.
- `plugConnect` — подключаю, интеграция, плагин к.
- `layerStack` — поверх, обёртка, стек, слой.
- `swarm` — сотни, тысячи, рой, завалило.
- `pathMorph` — превращается, становится, эволюция (плавный переход одной формы/идеи в другую).
- `annotate` — акцент на конкретной произносимой фразе («вот ЭТО/именно»), без отдельной карточки.
- `equals` — «то есть/по сути/иными словами» — переформулировка той же мысли.
- `suspenseQA` — «знаешь почему?/угадай что» — вопрос с холд-паузой перед ответом.
- `orbitDiagram` — экосистема, спутники вокруг ядра/центра.
- `pointer` — «смотри сюда/вот тут/видишь» — курсор указывает на элемент.
- `fullScreenText` — хук/панчлайн на весь экран.
- `progressBar` — загрузка, готовность, прогресс (0-100%).
- `lottieIcon` — чистая анимированная иконка (`gear`/`check`/`loader`) — репозиторий не содержит
  бандл Lottie-файлов, см. `LottieIcon.tsx`: нужен либо `https://`-URL на готовый Lottie JSON,
  либо файл, реально положенный в `public/lottie/`.
- `audioWave` / `audioSpectrum` — декор под голос (интро/связка/ритм-куски), не по маркеру речи.

## Чего в этом банке НЕТ (не предлагай, даже если фраза похожа)
Аналогия/метафора («это как…», «представь…»), браузерное/телефонное/дашборд-окно интерфейса,
allow-list/gate-барьер, дерево файлов, аудит-скан, диф-ревью, сверка двух колонок, сортировка по
корзинам, ранжирование списка, тумблер ❌→✅, динамический фон из цветных пятен — для всего этого
нет готового компонента. Не подставляй «примерно похожий» реальный тип вместо этого — либо
предложи нарисовать с нуля (см. `SKILL.md`), либо просто пропусти этот момент.
